# stick_drift_level_editor

Standalone level editor for stick_drift.

Saves and loads the same `stick_drift_level` JSON format used by the main game.

## Setup

```bash
nvm install
nvm use
npm install
npm start
```

## Controls

- Shift+S : save level
- Shift+L : load level
- 0 : toggle place / select mode
- 1 : cycle object category
- 2 : cycle brick type
- Shift+R : cycle spike facing
- Arrow keys : move camera
- F8 : cycle integer scale (Auto → 1x → 2x → 3x → 4x)
